## 📌 Про проєкт

Система автоматично знаходить та ідентифікує **10 типів інфраструктурних об'єктів** на супутникових знімках. В основі — архітектура **Siamese Triplet Network**, яка навчається розуміти *схожість* між зображеннями, а не просто запам'ятовувати класи.

Ключова перевага підходу: модель здатна узагальнюватись на нові об'єкти без перенавчання, порівнюючи нові зображення з відомими прикладами через метричний простір ембеддингів.

### 🎯 Задача

Дано: супутниковий знімок довільного розміру  
Знайти: де на знімку знаходяться задані типи об'єктів, з якою впевненістю

## 🧠 Архітектура

```
Вхід (224×224 px)
       │
       ▼
┌─────────────────────────────────────────┐
│          ResNet-50 Backbone             │
│      (ImageNet pretrained weights)      │
│              ↓ 2048                     │
├─────────────────────────────────────────┤
│           Embedding Head                │
│   Linear(2048→512) → BN → ReLU         │
│   → Dropout(0.3) → Linear(512→128)     │
│              ↓ L2-норм.                 │
└─────────────────────────────────────────┘
       │
       ▼
  Ембеддинг 128-dim (L2-нормалізований)
```

**Навчання:** Triplet Margin Loss з margin=1.0  
`L(a, p, n) = max(0, d(a,p) − d(a,n) + margin)`

Три зображення подаються одночасно: якір (anchor), позитивний приклад (той самий клас) та негативний (інший клас). Мережа навчається розміщувати схожі об'єкти поруч у метричному просторі.

## 🔍 Метод детекції: Multi-Scale Sliding Window

Для пошуку об'єктів на картографічних знімках довільного розміру реалізовано:

```
Вхідний знімок
      │
      ├─ Масштаб 0.3× → великі об'єкти
      ├─ Масштаб 0.5× → середньо-великі
      ├─ Масштаб 0.75× → середні
      ├─ Масштаб 1.0× → стандартні
      └─ Масштаб 1.5× → дрібні об'єкти
            │
            ▼
    Ковзне вікно 224×224 (крок 50%)
            │
            ▼
    Косинусна схожість з прототипами класів
            │
            ▼
    Non-Maximum Suppression (IoU ≥ 0.35)
            │
            ▼
    Топ-3 знахідки на клас з рамками
```

## 📊 Датасет

**NWPU-RESISC45** — Northwestern Polytechnical University Remote Sensing Image Scene Classification

- 🖼️ 31 500 зображень розміром 256×256 пікселів
- 🏷️ 45 класів об'єктів, 700 зображень на клас
- 📥 Доступний через [Hugging Face](https://huggingface.co/datasets/timm/resisc45)

**Розподіл даних:**

```
Весь датасет (10 класів, ~7000 зображень)
├── Train  70%  ~4900 зображень  ← навчання
├── Val    10%  ~700 зображень   ← підбір гіперпараметрів
└── Test   20%  ~1400 зображень  ← фінальне оцінювання (ізольований)
```
